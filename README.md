# 🧰 Local Service Hub – Final Major Project (Full Stack)

🔗 **Live Website:** [https://local-service-hub.42web.io/auth/login.php](https://local-service-hub.42web.io/auth/login.php)  
📁 **GitHub Repo:** [Local-service-hub](https://github.com/82PareshPatil/Local-service-hub)

> “Local Service Hub” is a full-stack web platform that connects **local users** to **verified service providers** such as plumbers, electricians, tutors, and more. Built for urban, rural, and hostel users — it simplifies service access in a trusted environment.

---

## 🎯 Objective

To create a digital ecosystem that:
- Bridges the gap between service seekers and local professionals
- Offers real-time booking, chat, and transaction support
- Ensures verified vendors, reviews, and transparent payments

---

## 👨‍💼 Key Roles

### ✅ Admin
- Full control dashboard
- Manage users, vendors, services, bookings, and payments
- Create coupons & verify transactions

### ✅ Vendors
- Register & create shop
- Add services with pricing
- Accept/reject bookings
- Chat with customers

### ✅ Users
- Register, login & search services
- Book and pay for services
- Follow vendors, review, and manage bookings

---

## ✨ Main Features

| Module       | Features                                                                 |
|--------------|--------------------------------------------------------------------------|
| 🧑 User      | Registration, booking, support, cart, coupon, history, secure login      |
| 🧑‍🔧 Vendor  | Shop & service add, profile, booking panel, chat                         |
| 🛠 Admin     | Dashboard, all bookings control, service listing, coupon, payments       |
| 💬 Chat      | Real-time message box between user and vendor                            |
| 💸 Payments  | Payment management, invoice view, UPI/cash option                        |
| 🔐 Security  | OTP login, hashed passwords, session handling                            |

---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Backend:** PHP (procedural)
- **Database:** MySQL (via phpMyAdmin)
- **Hosting:** InfinityFree
- **Authentication:** OTP verification, role-based login
- **Others:** AJAX, session management, form validation

---

## 🗃️ Database Tables

- `users`, `vendors`, `admins`, `shops`, `services`, `bookings`, `payments`
- `chats`, `notifications`, `coupons`, `followers`, `ratings`, `otp_verification`
